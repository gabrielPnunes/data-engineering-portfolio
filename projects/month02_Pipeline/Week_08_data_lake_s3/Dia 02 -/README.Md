- Preparar estrutura para Data Lake na nuvem

---

## Conceitos

### Amazon S3

- Serviço de armazenamento de objetos da AWS
- Escalável e altamente disponível
- Muito utilizado em:
  - Data Lakes
  - backups
  - analytics
  - pipelines ETL

---

### Bucket

- Estrutura principal do S3
- Equivalente a uma pasta raiz
- Armazena objetos (arquivos)

---

### Object Storage

- Dados armazenados como objetos
- Cada objeto possui:
  - arquivo
  - metadata
  - chave única

---

### Lifecycle Policy

- Automatiza gerenciamento de objetos
- Pode:
  - mover arquivos entre camadas
  - deletar arquivos antigos
  - reduzir custos
